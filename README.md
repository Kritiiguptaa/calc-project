# Calculator Project - Input Validation Edition

A small command-line calculator written in Python for the UCS 745 Cloud and DevOps
lab assignment. The point of the project is to practise the Git and GitHub
workflow: branching, pushing, merging and resolving a merge conflict by hand.

## Features

- Add two numbers
- Subtract two numbers
- Multiply two numbers
- Divide two numbers, with division-by-zero handled instead of crashing

## How to run

```
python calc.py
```

Then pick an option from 1 to 5 and enter two numbers when asked.

## Files

- `calc.py` - the calculator itself
- `README.md` - this file
- `GIT_STEPS.md` - a log of every Git command run, with its output
- `REFLECTION.md` - a reflective note on the merge conflict and what I learned
